## 4. 제품화 — «미리 선택 + 줄 고르기 UI(D)», PR 4개 순서

1. **상자를 돌려받기**: `OcrOutcome.Text`에 줄·어절 상자(자른 비트맵 좌표)를 싣는다 — `MlKitTextExtractor`가 이미 받는 `TextBlock.lines[].elements[].boundingBox`. 화면 변화 0, 단위 테스트(가짜 추출기). + 디버그 빌드 한정 «상자 덤프»(기준 자료 `boxes/mlkit-…/`로 옮길 TSV) — **기기 ML Kit 상자로 같은 자료를 다시 재는 길**.
2. **검출 연결(미리 선택만)**: 인식 뒤 같은 비트맵으로 `UnderlineDetector` → 고른 어절 표시값. 결과 글은 지금처럼 전부(동작 변화 0) — 기기에서 상자 덤프 + 미리 선택 결과를 기준 자료로 재 문턱을 고정.
3. **줄 고르기 UI(D)**: 결과 화면에 인식된 줄 목록(미리 선택된 어절 강조) → 눌러 넣고 빼기 → 고른 글만 편집창. 스크린샷 골든 + 화면 테스트. 문구를 «밑줄 인식»으로 되돌리는 것은 이 PR(LC DEC §4-1).
4. **형광펜(C) 켜기**: 형광펜 사진이 기준 자료에 3장 이상 들어온 뒤, 같은 측정으로 문턱 확인 후.

각 PR은 기준 자료 측정표를 PR 본문에 붙인다(수치가 내려가면 머지 0).
