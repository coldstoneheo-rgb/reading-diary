- **조건 3:** 인식 → 결과 글을 **먼저** `ocrState`에 → 인식 Job은 거기서 끝나고, 같은 비트맵으로 **따로 도는** 미리 선택 Job이 `UnderlinePreselect.forLines` → `underlinePreselect`(어절마다 선택 여부) → 그 Job이 끝날 때 비트맵 회수(시작 전 취소 포함, `invokeOnCompletion`). 결과가 나온 뒤에는 정밀 분석 · 새 인식 요청을 main과 똑같이 받는다(재게이트 보정 1 — `whilePreselectRuns_afterTheResult_preciseAnalysisAndNewRecognitionAreAccepted`). 새 인식 · 정밀 분석 시작 · 화면 리셋은 미리 선택을 취소하고 값을 비운다(정밀 결과로 바꾼 뒤 옛 값이 남지 않게). 결과 글은 상자 유무와 관계없이 같다(테스트로 고정). 화면은 `underlinePreselect`를 읽지 않는다. 미리 선택 실패(예외 · OOM)는 null로 삼켜 결과에 영향 0. 정밀 분석 경로는 미리 선택을 하지 않는다(테스트).
