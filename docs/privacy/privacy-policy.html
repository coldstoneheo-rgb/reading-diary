독서 다이어리 개인정보처리방침

시행일: [시행일 입력] · 앱 패키지: com.woodpeckerai.readingdiary · 문의: [연락처 이메일 입력]

독서 다이어리(이하 “앱”)는 계정과 서버가 없는 개인 독서 기록 앱입니다. 앱 개발자는 이용자의 기록·사진·검색어를 받아 보관하는 서버를 운영하지 않습니다. 이 방침은 앱이 어떤 정보를 기기 안에 두고, 어떤 경우에 기기 밖으로 무엇을 보내는지 사실대로 설명합니다.

1. 기기 안에 저장하는 정보

  • 책 정보(제목·저자·쪽수·표지 주소·읽기 상태), 책장, 독서 일기(밑줄 구절·메모·쪽·작성 시각), 기록에 남긴 사진, 화면 설정은 이 기기의 앱 저장소에 저장됩니다.
  • 설정에서 등록한 Gemini API 키는 기기의 암호화 저장소에만 저장되며, 암호화 저장소를 쓸 수 없으면 저장하지 않습니다.
  • 앱을 삭제하거나 앱 데이터를 지우면 위 정보는 함께 삭제됩니다. 앱 안에서 책·일기를 지우면 해당 기록이 삭제됩니다.

2. 사진

  • 밑줄 구절 인식은 기기 안에서 실행됩니다(Google ML Kit 한국어 글자 인식). 이 과정에서 사진은 기기 밖으로 전송되지 않습니다. 처음 사용할 때 Google Play 서비스가 인식 모델을 내려받을 수 있습니다.
  • 기록에 남긴 사진은 기록과 함께 앱 내부 저장소에 보관되며, 자동 백업·기기 간 자동 이전에서 제외됩니다. 이용자가 설정에서 직접 실행하는 «백업 파일 만들기»(zip)에만 포함되고, 기록·책을 지우면 함께 지워집니다. 촬영 임시 파일은 앱의 캐시 폴더에 잠시 남을 수 있으며 자동 백업에는 포함되지 않습니다.
  • 예외 — 아래 5항의 정밀 분석을 이용자가 직접 실행한 사진만 Google로 전송됩니다.

3. 도서 검색(카카오·Google)

  • 책을 추가할 때 검색창에 입력한 검색어(제목·저자·ISBN)가 카카오 책 검색 API(dapi.kakao.com)로 전송되어 검색 결과를 받습니다. 키가 없거나, 카카오에서 찾지 못하거나 오류가 나면 같은 검색어가 Google Books API(www.googleapis.com)로 전송됩니다.
  • 카카오 검색 결과에는 쪽수가 없어, 그중 한 권을 고르면 그 책의 ISBN이 쪽수 확인을 위해 Google Books API로 전송됩니다.
  • 앱은 검색어를 기기에도 기록하지 않습니다. 전송된 검색어의 처리는 각 서비스의 개인정보처리방침을 따릅니다.
  • 검색 결과의 표지 이미지를 화면에 표시할 때 해당 이미지 서버에 요청이 갑니다(기기의 IP 주소 등 일반적인 접속 정보가 그 서버에 전달됩니다).
  • ISBN 바코드 스캔은 Google Play 서비스의 코드 스캐너가 기기에서 처리하며, 앱은 인식된 숫자만 받아 검색창에 넣습니다.

4. 자동 백업

  • 안드로이드 자동 백업이 켜져 있으면 책·일기·일반 설정이 이용자 본인의 Google 계정 백업에 포함될 수 있습니다. 이 백업은 안드로이드 운영체제가 수행하며 앱 개발자는 접근할 수 없습니다.
  • API 키 저장소와 기록에 남긴 사진은 클라우드 백업과 기기 이전 모두에서 제외됩니다. 그래서 자동 백업으로 복원한 기록에는 사진이 없을 수 있습니다(설정의 «백업 파일 만들기»로 만든 zip에는 사진이 포함됩니다 — 6항).
  • 자동 백업은 기기의 설정 › Google › 백업에서 끌 수 있습니다.

5. 선택 기능: 정밀 분석(Google Gemini)

  • 이 기능은 이용자가 원할 때만 쓰는 선택 기능입니다. 다음 세 가지를 모두 거쳐야 실행됩니다.
    1. 설정에서 이용자 본인의 Google Gemini API 키를 등록
    2. “정밀 분석을 실행할 때마다 선택한 페이지 사진이 Google Gemini로 전송되는 것에 동의합니다” 체크
    3. 사진마다 뜨는 확인 창에서 “전송하고 분석”을 누름
  • 실행하면 선택한 페이지 사진이 이용자의 키로 Google(generativelanguage.googleapis.com)에 전송됩니다. 처리와 보관은 Google의 Gemini API 약관과 개인정보처리방침을 따르며, 요금은 키 소유자에게 청구됩니다.
  • 분석 결과는 이용자가 “이 결과로 바꾸기”를 눌러야 편집창에 들어갑니다. 키를 지우면 사진 전송 동의도 함께 해제됩니다.

6. 내보내기·복사·백업 파일

  • “마크다운으로 복사”는 기록을 기기의 클립보드에 복사합니다. 붙여 넣은 뒤의 처리는 이용자가 고른 앱을 따릅니다.
  • “마크다운 내보내기”(제공 시)는 이용자가 직접 고른 폴더에 책마다 새 파일을 만듭니다. 이미 같은 이름의 파일이 있으면 건드리지 않고 건너뜁니다. 파일은 이용자가 고른 저장 위치(기기 또는 그 위치가 연결된 서비스)에 저장되며 앱은 그 파일을 다른 곳으로 보내지 않습니다.
  • 내보낸 파일을 앱으로 다시 가져오는 기능은 없습니다(백업·복원 기능이 아닙니다).
  • 설정의 “백업 파일 만들기”는 책·책장·일기·기록에 남긴 사진을 zip 파일 하나로 만들어 이용자가 직접 고른 저장 위치(기기 또는 그 위치가 연결된 서비스, 예: 본인 Google 드라이브)에 저장합니다. API 키 저장소와 앱 설정은 넣지 않습니다. 이용자가 버튼을 누를 때만 실행되며(예약·자동 실행 없음), 앱은 그 파일을 다른 곳으로 보내지 않습니다.
  • “백업 파일에서 복원”은 이용자가 고른 zip으로 지금 기록을 바꿉니다(합치지 않음). 파일을 먼저 검사하고 통과할 때만 바꾸며, 도중에 실패하면 지금 기록을 그대로 둡니다.

8. 아동

앱은 아동을 대상으로 하지 않으며, 연령 정보를 수집하지 않습니다.

9. 변경

이 방침이 바뀌면 이 페이지의 시행일을 갱신합니다. 정보를 기기 밖으로 보내는 새 경로가 생기면 앱 업데이트 전에 이 페이지에 먼저 반영합니다.
